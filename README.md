# Create Netherite Stuff 'N Additions

Netherite upgrade for the Portable Drill from **Create Stuff 'N Additions**.

This mod adds one focused thing: a stronger netherite version of the portable drill, built for players who like the original gadget but want it to stay useful deeper into the game.

## Features

- **Netherite Portable Drill** - an upgraded portable drill with netherite mining tier.
- Mines blocks faster than a netherite pickaxe when supplied with fuel and water.
- Can mine blocks that require netherite-tier tools.
- Uses **fuel** and **water** instead of durability.
- Shows separate fuel and water bars in the inventory, like the original drill.
- Supports the same style of enchantments as the original drill.
- Works with Create Stuff 'N Additions filling and fueling tanks.
- Includes JEI support for smithing, anvil enchantments, and item information.

## How To Get It

Upgrade the regular **Portable Drill** from Create Stuff 'N Additions at a smithing table:

- Netherite Upgrade Smithing Template
- Portable Drill
- Netherite Ingot

JEI will show the exact recipe in-game.

## Fuel And Water

The drill needs both resources to work at full power:

- fuel goes into the fuel tank;
- water goes into the water tank.

You can refill it with compatible Create Stuff 'N Additions tanks, or manually with supported fuel and water items.

The netherite drill has a slightly larger tank than the original portable drill.

## Requirements

- Minecraft **1.21.1**
- NeoForge **21.1+**
- Create **6.0.10+**
- Create Stuff 'N Additions **2.1.4+**

Optional:

- JEI, for recipe and item information.

## Notes

This is an addon for Create Stuff 'N Additions. It is not an official Create or Create Stuff 'N Additions project.

Some model and texture work is based on assets from Create Stuff 'N Additions and modified for the netherite drill.
